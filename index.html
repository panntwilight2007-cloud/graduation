Demo / Local Mode

☁️ ကိုယ်ရေးလိုက်တဲ့ စာတွေကို တခြားသူတွေပါ အမြဲမြင်ရအောင် Firebase ချိတ်ဆက်နည်း

လက်ရှိမှာ Firebase Config မထည့်ရသေးရင် စာတွေကို ဒီစက်ထဲမှာပဲ (Local Storage) သိမ်းပေးထားပါမယ်။ တခြားဖုန်း/ကွန်ပျူတာတွေကနေ လင့်ခ်ဖွင့်ကြည့်ရင်ပါ အချင်းချင်း စာတွေမြင်ရဖို့ အောက်ပါအတိုင်း လုပ်ဆောင်ပါ -

  1. console.firebase.google.com မှာ Project အသစ်တစ်ခု ဖန်တီးပါ။
  2. ဘယ်ဘက်မီနူးက Build > Firestore Database ကိုနှိပ်ပြီး Create database (Test mode) ကို ရွေးပါ။
  3. Project Settings ထဲကနေ Web App (</>) တစ်ခုထည့်ပြီး ရလာတဲ့ firebaseConfig ကုဒ်ကို ကူးယူပါ။
  4. ဒီ graduation.html ဖိုင်ရဲ့ အောက်ဆုံးနားက const firebaseConfig = { ... }; နေရာမှာ အစားထိုးထည့်ပြီး GitHub ပေါ် ပြန်တင်လိုက်ရုံပါပဲ!
